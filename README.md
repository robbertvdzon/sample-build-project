# sample-build-project

Een Kotlin/Spring Boot webapplicatie met een Thymeleaf homepage.

## Starten

```sh
./gradlew bootRun
```

Open http://localhost:8080 in je browser.

## Bouwen

```sh
./gradlew build
```

> **Let op**: zorg dat `gradle/wrapper/gradle-wrapper.jar` aanwezig is. Genereer deze eenmalig met `gradle wrapper --gradle-version 8.7`.

## Documentatie

Zie `docs/factory/` voor technische specificaties, ontwikkelconventies en factory-docs.
