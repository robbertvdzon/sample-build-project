# Agent Tips

## kotlin_spring / gradle_wrapper_jar

gradle/wrapper/gradle-wrapper.jar is een binair bestand (~43KB) dat niet met de Write-tool aangemaakt kan worden. Als Bash beschikbaar is, download het dan direct van GitHub:
`curl -fsSL -o gradle/wrapper/gradle-wrapper.jar "https://github.com/gradle/gradle/raw/vX.Y.0/gradle/wrapper/gradle-wrapper.jar"`
(vul de Gradle-versie in, bijv. v8.7.0). Als Bash niet beschikbaar is, noteer dit in de story-log; de factory genereert het dan.

## gradle / gradlew_chmod

Controleer bij Gradle-projecten altijd of 'gradlew' de juiste git-index permissie heeft (100755). Gebruik `git ls-files --stage gradlew` om dit te verifiëren. Mode 100644 betekent dat ./gradlew mislukt met 'Permission denied' op Linux/macOS. Fix: `git update-index --chmod=+x gradlew`. Zet ook de filesystem-permissie met `chmod +x gradlew` voor de huidige sessie.

## tooling / bash_unavailable_erofs

In sommige sandbox-runs is de Bash-tool volledig niet beschikbaar door een EROFS-fout op /home/runner/.claude/session-env/. Gebruik in dat geval alleen Read/Write/Edit/Glob/Grep. Git-commits en chmod moeten dan door de factory worden uitgevoerd. De Write-tool werkt wel normaal voor /work/repo.
