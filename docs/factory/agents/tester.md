# Tester Instructions

- Lees `deployment.md` en `secrets-local.md` voordat je test.
- Start de applicatie lokaal met `./gradlew bootRun` en open http://localhost:8080.
- Controleer:
  - Paginatitel is "Test web app"
  - Heading toont "Test web app"
  - Body bevat "dit is een test web applicatie"
- Rapporteer bugs met reproductiestappen, verwacht gedrag en werkelijk gedrag.
