# Tester Instructions

- Lees `deployment.md` en `secrets-local.md`.
- Start de applicatie via `./gradlew bootRun` en open `http://localhost:8080/`.
- Verifieer dat de pagina titel `Test web app` en tekst `dit is een test web applicatie` toont.
- Rapporteer bugs met concrete reproductiestappen en verwacht/werkelijk gedrag.
